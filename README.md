# Sailfish cards

Code shared by the Sailfish OS card games [Bridge](https://github.com/klahr/bridge),
[Cribbage](https://github.com/klahr/cribbage) and [Hearts](https://github.com/klahr/hearts),
a submodule of each.

- `cards.pri`: the cards, in C++ and QML
- `online.pri`: online play through [cards-server](https://github.com/klahr/cards-server),
  with the lobby and table pages
